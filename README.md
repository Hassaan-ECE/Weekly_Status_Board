# Weekly Status Board

Personal Windows desktop board for weekly manager updates. Cards move Target → In Progress → Done, grouped by project. Copy/Export PNG pastes into PowerPoint.

Built with **GPUI**. After it ships, treat this repo as the GPUI reference for later apps (theme, window shell, JSON files, PNG export).

**Status:** design spec approved. Implementation has not started.
